# Getting Started

Follow these steps to start this Selenium project:

## Prerequisites

- Python installed (version 3.7+ recommended)
- Google Chrome or Firefox browser
- ChromeDriver or GeckoDriver installed and added to PATH

## Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/your-repo.git
    cd your-repo
    ```

2. **Create a virtual environment (optional but recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3. **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## Running the Project

4. **Run your Selenium scripts:**
    ```bash
    python your_script.py
    ```

## Notes

- Make sure the appropriate WebDriver (ChromeDriver/GeckoDriver) is installed and matches your browser version.
- Update `requirements.txt` as needed for additional dependencies.
